Keep the human review. Lose the grind.

Agents write code faster than people can review it. Here the agent reads the merge request first, cuts it into small steps in a sensible order and walks you through them. You decide what is wrong; it writes the comments and posts them when you say so.

Install GitHub
  • Chapters by behaviour, not by file: spec, contracts, entry points, then the code they call.
  • ⚑ hotspots where a mistake is expensive — money, security, consistency, migrations.
  • Every step needs your “next” or a reason to skip. Nothing is posted without your yes.
01

Say it in your own words

Point at a line and write what bothers you, the way you would say it to a colleague. The agent turns it into a review comment with a severity and, when the fix is obvious, a suggestion. When it needs a decision, it offers answers you pick with one key.

02

No rubber stamp

A step counts as reviewed only when you move past it or skip it with a reason. The viewer tracks which changed lines you actually scrolled past and reminds you once about the rest, or about a hotspot nobody discussed.

03

Round two starts where you left off

After the author pushes, you see only what changed since your last round. Your open threads come first, with the author's replies. The agent checks each reply against the new code and suggests resolve or keep open. You decide.

04

Nothing is posted before you see it

At the end you see every inline comment and the summary exactly as they will be posted. Edit, delete, change a severity. Only after your yes does the agent publish: GitLab draft notes in one batch, or one GitHub review.

Install

Ask your agent

Paste this into Claude Code or Codex. It checks the prerequisites, installs gr and the skills, and tells you what is left for you.

Install guided-review from https://github.com/pltanton/guided-review, follow its INSTALL.md

By hand

Go, tmux and glab or gh first; then:

go install github.com/pltanton/guided-review/cmd/gr@latest
claude plugin marketplace add pltanton/guided-review
claude plugin install guided-review@guided-review

Then, in tmux inside the repository

/guided-review https://gitlab.example.com/group/project/-/merge_requests/123

The recordings run the real gr viewer on a demo repository. The agent's side is scripted so every take is the same; in a real review Claude Code or Codex says these lines.
