Keep the human review.
Lose the grind.

Agents write code faster than people can review it. guided-review has the agent read the merge request first, cut it into small steps in an order that makes sense and walk you through them in a terminal viewer. You decide what is wrong. It writes the comments and posts them when you say so.

Install Source on GitHub

It does not review for you

Every step needs your “next” or a skip with a reason. The judgement stays yours.

Small steps, sensible order

Spec, contracts, then each entry point and the code it calls, tests right after. About 300 changed lines a step.

Nothing leaves without you

gr never writes to the merge request. You see the whole result before the agent posts it.

01

Say it in your own words

Point at a line and write what bothers you, the way you would say it to a colleague. The agent turns it into a review comment with a severity and, when the fix is obvious, a suggestion. When it needs a decision, it offers answers you pick with one key.

02

A diff that reads like code

Moved code is marked as moved instead of shown twice. Large deletions fold away. Only the words that changed inside a line are coloured. With a language server you jump to definitions and callers, and FLOW shows who calls the functions this step changed.

03

No rubber stamp

A step counts as reviewed only when you move past it or skip it with a reason. The viewer tracks which changed lines you actually scrolled past and reminds you once about the rest, or about a hotspot nobody discussed. Ask the agent anything on the way; it answers from the code.

04

Round two starts where you left off

After the author pushes, you see only what changed since your last round. Your open threads come first, with the author's replies. The agent checks each reply against the new code and suggests resolve or keep open with a reply. You decide.

05

Nothing is posted before you see it

At the end you see every inline comment and the summary exactly as they will be posted. Edit a comment, delete it, change its severity. Only after your yes does the agent publish: GitLab draft notes in one batch, or one GitHub review.

Install

Ask your agent

Paste this into Claude Code or Codex. It checks the prerequisites, installs gr and the skills, and tells you what is left for you.

Install guided-review from https://github.com/pltanton/guided-review, follow its INSTALL.md

By hand

Go, tmux and glab or gh first; then:

go install github.com/pltanton/guided-review/cmd/gr@latest
claude plugin marketplace add pltanton/guided-review
claude plugin install guided-review@guided-review

Then, in tmux inside the repository

/guided-review https://gitlab.example.com/group/project/-/merge_requests/123

The recordings run the real gr viewer on a demo repository. The agent's side is scripted so every take is the same; in a real review Claude Code or Codex says these lines.
